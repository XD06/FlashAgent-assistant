# Code of Conduct

## Our Pledge

We want this project to be a welcoming, respectful, and constructive space for everyone.

## Expected Behavior

- Be respectful and considerate
- Focus on ideas, code, and product outcomes rather than personal attacks
- Give feedback that is specific and helpful
- Assume good intent while still being honest and clear

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks
- Trolling or deliberately disruptive behavior
- Publishing private information without permission
- Repeated bad-faith interactions

## Enforcement

Project maintainers may remove comments, close discussions, or block contributions that violate this code of conduct.

For serious concerns, use the private contact path described in [SECURITY.md](./SECURITY.md) or your project’s designated maintainer contact.
